Chrome Extension Installation Guide

Professional Screen Recording & Capture Tool

📥 Download Extension Files

Since this extension is not yet published on the Chrome Web Store, you'll need to install it manually.

Note: The extension files are located in the project's chrome-extension folder. You can access them directly from the project directory.
📁 Access Extension Folder 🔗 GitHub Repository

🚀 Installation Steps

Step 1: Locate Extension Files

Navigate to the chrome-extension folder in your project directory:

📁 your-project/chrome-extension/

This folder contains all the necessary extension files including manifest.json, popup files, and scripts.

Step 2: Open Chrome Extensions

Open Google Chrome and navigate to:

chrome://extensions/

Or go to Menu → More Tools → Extensions

Step 3: Enable Developer Mode

Toggle the "Developer mode" switch in the top-right corner of the extensions page.

Important: Developer mode must be enabled to install unpacked extensions.

Step 4: Load Extension

Click the "Load unpacked" button and select the chrome-extension folder.

The extension should now appear in your extensions list and toolbar.

Step 5: Grant Permissions

When you first use the extension, Chrome will ask for permissions:

  • Screen capture access
  • Microphone access (for audio recording)
  • Download permissions

Grant these permissions to enable full functionality.

✨ Features

  • High-quality screen recording (up to 1080p, 30fps)
  • Screenshot capture with area selection
  • Audio recording (microphone + system audio)
  • Keyboard shortcuts (Ctrl+Shift+R, Ctrl+Shift+C)
  • Multiple image formats (PNG, JPEG, WebP)
  • Recent captures history
  • Privacy-focused (no data collection)
  • Works on all websites

⌨️ Keyboard Shortcuts

Default Shortcuts

Ctrl+Shift+R - Start/Stop screen recording

Ctrl+Shift+C - Take screenshot

Escape - Cancel area selection

🔧 Troubleshooting

Extension Not Loading

• Make sure you selected the correct chrome-extension folder

• Check that all required files are present

• Try refreshing the extensions page

Recording/Screenshot Not Working

• Grant all requested permissions

• Refresh the webpage and try again

• Check that no other screen recording software is running

Audio Not Recording

• Grant microphone permissions when prompted

• Check system microphone settings

• Ensure microphone isn't being used by other apps
