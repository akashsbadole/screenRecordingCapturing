🔧 Technical Fix Details

Problem: The background script was trying to create canvas elements and manipulate images, but this doesn't work in Manifest V3 service workers.

Solution: Moved the canvas processing to the page context where DOM manipulation is allowed.

How it works now:

  1. User selects area with overlay
  2. Background script captures full screenshot
  3. Coordinates and image sent to page context
  4. Page context creates canvas and crops image
  5. Cropped image downloads automatically
