📷 Full Screen Capture
Captures the entire visible screen area. This is the basic screenshot functionality that should work reliably.
🎯 Capture Area
Click and drag to select a custom area to capture. Shows overlay with selection box and instructions.
📜 Full Page Capture
Captures the entire page by scrolling and stitching multiple screenshots together. Perfect for long pages.
⏰ Delayed Capture
Shows a 3-second countdown before taking a screenshot. Useful for capturing menus or hover states.
🪟 Window Capture
Lets you select a specific window to capture. Uses Chrome's desktop capture API for window selection.
📹 Camera Test
Tests camera access and shows camera details. Useful for verifying camera works before recording.
