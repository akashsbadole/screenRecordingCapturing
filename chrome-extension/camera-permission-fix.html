🔧 How to Fix Camera Permissions

🌐 Chrome/Edge

  1. Look for camera icon in address bar
  2. Click it and select "Always allow"
  3. Or go to Settings > Privacy > Camera
  4. Add this extension to allowed sites

🦊 Firefox

  1. Click shield icon in address bar
  2. Select "Allow" for camera access
  3. Or go to Settings > Privacy > Permissions
  4. Manage camera permissions

📋 Step-by-Step Permission Fix
  1. Check Camera Hardware: Ensure your camera is connected and working in other applications
  2. Close Other Apps: Close Zoom, Skype, Teams, or other apps using the camera
  3. Grant Browser Permission: Allow camera access when prompted by the browser
  4. Check Browser Settings: Go to browser settings and ensure camera access is allowed
  5. Test Extension: Use the "Test Camera" button in the extension popup
  6. Restart if Needed: Restart your browser if permission changes don't take effect
🎯 Troubleshooting Guide

If Camera Still Doesn't Work:

🔍 Check System Camera:
  • Open Camera app on Windows/Mac to verify camera works
  • Check Device Manager (Windows) or System Preferences (Mac)
  • Update camera drivers if needed
🌐 Browser-Specific Issues:
  • Clear browser cache and cookies
  • Disable other extensions temporarily
  • Try incognito/private mode
  • Update browser to latest version
🔒 Security Software:
  • Check antivirus camera protection settings
  • Temporarily disable camera privacy software
  • Add browser to security software exceptions
