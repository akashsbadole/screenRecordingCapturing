Installation Verification

📋 Installation Steps

  1. Open Chrome and go to chrome://extensions/
  2. Enable "Developer mode" (toggle in top right)
  3. Click "Load unpacked" button
  4. Select the chrome-extension folder
  5. Extension should appear in your toolbar
  6. Click the extension icon to test functionality

⚠️ Known Issues

  • Context menu may not work on first load (reload extension)
  • Camera access requires user permission
  • Some features require specific Chrome permissions
  • Screen recording quality depends on system performance

🔧 Troubleshooting

  • Extension not loading: Check manifest.json for errors
  • Permissions denied: Grant camera/microphone access when prompted
  • Recording not starting: Close other recording software
  • Context menu missing: Reload the extension
  • Performance issues: Lower recording quality settings
