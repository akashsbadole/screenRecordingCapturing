🐛 Debug "Invalid State" Error

Common Causes of "Invalid State" Error:

  • Video not ready: Trying to draw from video before it's loaded
  • Stream ended: Video stream was stopped before capture
  • Canvas context issues: Canvas not properly initialized
  • Timing issues: Operations happening too quickly
🧪 Enhanced Debug Test

Step-by-Step Debug Process:

  1. Open DevTools: Press F12 to open browser console
  2. Reload Extension: Go to chrome://extensions/ and reload
  3. Test Window Capture: Click extension → Capture → "Capture Window"
  4. Monitor Console: Watch for debug messages and errors
  5. Check Error Details: Look for specific error messages

❌ Error Scenarios to Watch For:

Error drawing video to canvas: InvalidStateError
Video not ready for capture, readyState: 1
Video has invalid dimensions: 0x0
Failed to draw video frame: The video element's readyState is HAVE_NOTHING
Generated image data is invalid or too small
🔧 Troubleshooting Steps

If you see "Invalid State" error:

  1. Check readyState: Should be 2 or higher (HAVE_CURRENT_DATA)
  2. Verify dimensions: Video width/height should be > 0
  3. Wait longer: Video might need more time to load
  4. Check stream: Desktop capture stream might be invalid
